# Classi (Classes): regole generali e riepilogo

## Selezione della Class

- Le Class presentate nel manuale sono le opzioni che compaiono nei libri e sono disponibili alla maggior parte dei crawler.
- La scelta della Race influenza le tre opzioni di Class offerte dal System AI. Il giocatore discute le proprie preferenze con il GM prima della selezione.
- Le Class sono suddivise in categorie. La categoria principale è la base Class: Barbarian, Bard, Cleric e Mage sono categorie di Class simili.
- Ogni Class riporta uno o più **Class Type**. Le Class con più Class Type compaiono una sola volta, nel gruppo in cui le colloca il manuale (nella documentazione, nel file di quel gruppo).
- Le tabelle di crafting ottenute tramite la Class compaiono non appena il crawler ottiene uno spazio personale (Fourth Floor o successiva).
- Il giocatore può progettare una Class personalizzata con il sistema Class Point Buy (vedi il file *Sistema Point Build*). Diverse Class del manuale hanno benefici che non compaiono nelle tabelle dei costi.

*Fonte: manuale, p. 142.*

## Earth Classes

- Le **Earth Classes** sono disponibili solo ai crawler che scelgono una Race basata sulla Terra (Earth-based Race; vedi la sezione *Race*).
- Chi seleziona una Earth Class ottiene una **Silver Earth Box** (descritta nella sezione del GM, p. 321 del manuale).
- La Silver Earth Box contiene una **Earth Hobby Potion**, che garantisce 3 Skill Ranks in uno dei passatempi della Terra, più almeno un oggetto bonus.
- Le Earth Classes sono contrassegnate nel manuale dall'icona di una biglia (marble) accanto al nome. Nel testo regole, la presenza della Silver Earth Box è elencata tra le capacità della Class.

!!! warning "Da verificare"
    Le Class Herbalist e Santero riportano l'icona Earth Class accanto al nome, ma il testo non elenca la Silver Earth Box (p. 148–149).

*Fonte: manuale, p. 142.*

## Class limitate e restrizioni ricorrenti

- Una **Class limitata** ("limited Class") è disponibile solo ai crawler che soddisfano il prerequisito indicato (Race, sesso, Skill Rank, achievement, Popularity).
- Le Class Cleric e Paladin richiedono di venerare una divinità (vedi la sezione *Deities & Worship*).
- Alcune Class non possono essere scelte se il crawler ha accesso al Desperado Club (Class Cleric e Paladin) o a Club Vanquisher (alcune Class Rogue). Le restrizioni sono riportate per ciascuna Class nella tabella seguente.

*Fonte: manuale, p. 148–158.*
